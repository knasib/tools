### Install Dependencies ###
XmlGenerator uses two dependencies. Those are:
1. PyYAML : Read configuration from yaml file
2. Pandas : Read data from Excel

# install yaml for reading yaml file
pip install PyYAML

# install pandas for reading data from excel
pip install pandas
pip install openpyxl



### How to Run ###
Once all dependencies are installed, run the below command

Nagivate inside the root directory in command promt.
Command: `python main.py`
